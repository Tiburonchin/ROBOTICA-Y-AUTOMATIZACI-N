Ejercicio 1

EP-01 Garra Paralela - Selección

Pregunta

Se requiere una garra paralela para manipular botellas de vidrio de 0.5 kg en una línea de embotellado. La aceleración máxima del brazo robótico es 3 m/s². La presión disponible es 5.5 bar. Con FS = 2.0 y η = 0.82, calcule:

  • (a) Fuerza mínima requerida.
  • (b) Área mínima del pistón.
  • (c) Diámetro mínimo del pistón.

Resolución

1

Fuerza Dinámica Total: Considera la gravedad (g = 9.81 m/s²) y la aceleración del robot:
F_din = m · (g + a) = 0.5 kg · (9.81 + 3) m/s² = 6.405 N

2

Fuerza Mínima con FS:
F_req = F_din · FS = 6.405 N · 2.0 = 12.81 N

3

Área Mínima del Pistón: Ajustado por eficiencia (η = 0.82) y presión en Pascales (5.5 bar = 550,000 Pa):
A_min = F_req / (P · η) = 12.81 / (550,000 · 0.82) = 2.84e-5 m² = 28.40 mm²

4

Diámetro Mínimo:
D_min = √(4 · A_min / π) = 6.01 mm

Resultados del Ejercicio (PDF)

Fuerza Requerida (a): 12.81 N
Área Mínima (b): 28.40 mm²
Diámetro Mínimo (c): 6.01 mm

Control de Parámetros

Masa (m): 0.5 kg
Aceleración (a): 3.0 m/s²
Presión (P): 5.5 bar

Ejercicio 2

EP-02 Garra Angular - Verificación

Pregunta

Una garra angular existente tiene pistón Ø 25 mm, trabaja a 4 bar, η = 0.78 y K_brazo = 0.65. Se le quiere asignar una tarea de sujetar piezas de 2 kg con aceleración de robot 5 m/s². Determine si la garra es apta con FS = 2.0. Si no lo es, ¿qué presión mínima sería necesaria?

Resolución

1

Fuerza Requerida:
F_req = m · (g + a) · FS = 2 · (9.81 + 5) · 2.0 = 59.24 N

2

Área del Pistón Existente:
A = π · D² / 4 = π · 25² / 4 = 490.87 mm² = 4.9087e-4 m²

3

Fuerza Disponible en la Garra:
F_disp = P · A · η · K_brazo = 400,000 Pa · 4.9087e-4 m² · 0.78 · 0.65 = 99.55 N

4

Conclusión: Como 99.55 N > 59.24 N, la garra es APTA. En caso contrario, la presión mínima requerida se calcularía como:
P_min = F_req / (A · η · K_brazo)

Resultados del Ejercicio (PDF)

Fuerza Requerida: 59.24 N
Fuerza Disponible: 99.55 N
Veredicto: APTA (Suficiente con 4 bar)
Presión Mínima: 2.38 bar

Control de Parámetros

Masa de Pieza: 2.0 kg
Aceleración: 5.0 m/s²
Presión Actual: 4.0 bar

Ejercicio 3

EP-03 Mesa XY - Selección de Cilindros

Pregunta

Diseñar una mesa XY para posicionar un módulo de soldadura de 8 kg. Eje X: carrera 400 mm, aceleración 1.5 m/s². Eje Y: carrera 200 mm, aceleración 1.5 m/s². Presión: 6 bar, η = 0.90, FS = 2.0. Determine el diámetro del émbolo para cada eje y la fuerza real disponible.

Resolución

1

Fuerza Dinámica Requerida (Mov. Horizontal):
F_req = m · a · FS = 8 kg · 1.5 m/s² · 2.0 = 24.0 N

2

Área Mínima del Embolo:
A_min = F_req / (P · η) = 24.0 / (600,000 · 0.90) = 4.44e-5 m² = 44.44 mm²

3

Diámetro Mínimo:
D_min = √(4 · A_min / π) = 7.52 mm

4

Fuerza Real con Diámetro Estándar Comercial (e.g. D = 10 mm):
F_real = P · A_real · η = 600,000 · (π · 0.01² / 4) · 0.90 = 42.41 N

Resultados del Ejercicio (PDF)

Fuerza Requerida: 24.0 N
Diámetro Mínimo: 7.52 mm
Fuerza Real (D=10mm): 42.41 N

Control de Parámetros

Masa del Módulo: 8.0 kg
Aceleración: 1.5 m/s²
Posicionador Mesa XY

EP-04 Mesa XY - Tiempo de Ciclo

Pregunta

Para la mesa XY del ejercicio EP-03, si se regulan los caudales a: eje X = 20 L/min, eje Y = 12 L/min, y los diámetros elegidos son D_X = 50 mm, D_Y = 40 mm. Calcule: (a) velocidades de cada eje, (b) tiempos de desplazamiento, (c) tiempo total de ciclo X+ → Y+ → Y- → X-.

Resolución

1

Conversión de Caudales:
Q_X = 20 L/min = 3.33e-4 m³/s
Q_Y = 12 L/min = 2.00e-4 m³/s

2

Áreas de Cilindros:
A_X = π · 0.05² / 4 = 1.963e-3 m²
A_Y = π · 0.04² / 4 = 1.257e-3 m²

3

Velocidades de Eje:
V_X = Q_X / A_X = 0.170 m/s
V_Y = Q_Y / A_Y = 0.159 m/s

4

Tiempos de Ciclo:
t_X = 0.40 m / 0.170 m/s = 2.35 s
t_Y = 0.20 m / 0.159 m/s = 1.26 s
t_total = 2 · (t_X + t_Y) = 7.22 s

Resultados del Ejercicio (PDF)

Velocidades: V_X = 0.170 m/s | V_Y = 0.159 m/s
Tiempos Despl.: t_X = 2.35 s | t_Y = 1.26 s
Tiempo Total Ciclo: 7.22 s

Caudales y Diámetros

Caudal X (Q_X): 20 L/min
Caudal Y (Q_Y): 12 L/min
