EP-01 Garra Paralela - Selección

Se requiere una garra paralela para manipular botellas de vidrio de 0.5 kg. Aceleración máxima del brazo 3 m/s², presión 5.5 bar, FS = 2.0 y η = 0.82.

Fuerza Mínima: N
Área Mínima: mm²
Diámetro Mínimo: mm

EP-02 Garra Angular - Verificación

Una garra angular existente tiene pistón Ø 25 mm, trabaja a 4 bar, η = 0.78 y K_brazo = 0.65. Tarea: sujetar piezas de 2 kg con aceleración de 5 m/s². Determine si es apta con FS = 2.0.

Fuerza Requerida: N
Fuerza Disponible: N
Presión Mínima Sugerida: bar

EP-03 Mesa XY - Selección de Cilindros

Diseñar una mesa XY para módulo de 8 kg. Eje X (carrera 400 mm, a = 1.5 m/s²), Eje Y (carrera 200 mm, a = 1.5 m/s²). Presión: 6 bar, η = 0.90, FS = 2.0.

Fuerza Requerida (X e Y): N
Diámetro Mínimo (X e Y): mm
Fuerza Real (con D = 10mm): N

EP-05 Diseño de Sistema Completo

Sistema neumático propuesto para célula pick & place.

  • Unidad FRL: G1/4", presión máx 10 bar, filtrado 40 µm.
  • Garra Paralela: Doble efecto, fuerza mín > 60N, para piezas de 1.5kg.
  • Cilindros Mesa XY: Sin vástago o de doble efecto con guías. X: D=25mm, C=250mm. Y: D=25mm, C=150mm.
  • Válvulas Distribuidoras: 3 x Electroválvulas 5/2 biestables (para X, Y y Garra).
  • Reguladores de Caudal: 6 x reguladores unidireccionales para control de velocidad.
  • Sensores: 6 x sensores magnéticos (finales de carrera) + sensor de presión.
  • Controlador: PLC Compacto (ej. S7-1200) con mín. 8 entradas y 6 salidas a relé/transistor.
